# 文件与目录

- 新增文件前先检查现有结构和框架约定，沿用项目已有组织方式。
- 根目录只保留必要的入口、配置及标准文件；不要散放调试输出、草稿和一次性脚本。
- 工程文档放 `docs/`，维护脚本放 `scripts/`，测试放框架约定或模块对应的测试目录。
- 临时分析、下载、渲染、测试项目放 `.tmp/` 或系统临时目录，结束后清理本次产生的文件；不得误删用户文件。
- 项目运行需要的资源放入对应模块或资源目录，不能放到会被清理的临时目录。
- Agent 通用规则放 `.agent/rules/`，技术栈规则放 `.agent/stack.md`，项目补充规则放 `.agent/project.md`。
- 项目 Skills 使用安装器生成的 `.agents/skills/` 与 `.claude/skills/`；这些目录是副本，长期修改回源仓库进行。
- 项目记忆放 `.workbuddy/`，不得将记忆、日志或备份混入 Skills。
- 不硬编码本机用户名、盘符和私有绝对路径；可复用文件使用相对路径或显式配置。
- 清理、移动前核实实际目标位于本项目或本任务专属临时目录，避免对推导出的未检查路径递归操作。
