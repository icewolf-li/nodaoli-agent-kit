# 规则维护

规则描述个人默认行为，不绑定某个 Agent 品牌或本机环境。`templates/` 仅负责让不同 Agent 读取安装后的规则。

- `general.md`：交流与自主执行边界。
- `file-placement.md`：优先沿用现有工程结构，规范新增文件位置。
- `coding.md`：实现范围、依赖、错误处理与验证。
- `git.md`：差异保护、分支、提交与远程操作。
- `memory.md`：项目记忆的读取、记录与整理。

这版规则只把用户明确提出的仓库方向与当前可确认的协作需求落成默认值，不把引用对话里助手推荐的框架与架构当成用户事实。以后用户确认具体偏好，直接修改对应规则；不要在每个 Agent 入口里维护第二份内容。

项目特殊要求放 `.agent/project.md`；技术栈共性放 `stacks/<name>.md`；需要明确触发场景与执行步骤的工作流才放 `skills/<name>/SKILL.md`。
